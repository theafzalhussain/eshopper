### STEP 1: Update src/index.js
```javascript

root.render(
  <Provider store={store}>
    <PremiumMembershipProvider>  {/* Add this line */}
      <App />
    </PremiumMembershipProvider> {/* Add this line */}
  </Provider>
)
```

### STEP 2: Update src/Component/Navbaar.jsx
